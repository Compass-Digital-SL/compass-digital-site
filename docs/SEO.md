## Goals
- Rank for core services in Sri Lanka (websites, SEO, POS systems, apps, ecommerce, custom software).
- Rank for service × industry combinations (e.g. POS systems for restaurants).
- Turn search visits into quote requests.

## Site structure (draft)
- `/services/<service>/`
- `/industries/<industry>/`
- `/work/<case-study>/`
- `/about/`, `/process/`, `/faq/`, `/insights/`
- `/request-a-quote/`

## Technical baseline (to implement in Task 16)
- One `<h1>` per page, logical heading order.
- Unique title and meta description per page.

- Open Graph and Twitter card tags.
- Clean permalinks, no thin or duplicate pages.
